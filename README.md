# Генератор российских номеров 🎰

Игровой генератор автомобильных номеров России в тёмной теме. Крути барабаны,
выбивай случайные номера формата `А123ВС` с кодом региона и трать монеты.

## Структура проекта

```
├── index.html          # Главная страница: заголовок, canvas 800x400, кнопка, баланс
├── style.css           # Стили тёмной темы
├── script.js           # Логика генерации и отрисовки (пока минимальная)
└── data/
    └── regions.json    # 10 регионов России (код, название)
```

## Как запустить

Так как регионы загружаются через `fetch`, нужен локальный сервер
(просто открыть `index.html` двойным кликом — тоже можно, но тогда
сработает встроенный фолбэк-список регионов без загрузки JSON):

```bash
# вариант 1: Python
python3 -m http.server 8000

# вариант 2: Node.js
npx serve .
```

Затем открой в браузере: http://localhost:8000

## Что умеет (текущая версия)

- При клике на кнопку **«Крутить номер»** генерируется случайный номер
  (буквы только из разрешённого набора: А, В, Е, К, М, Н, О, Р, С, У, Х, Т);
- Номер рисуется на canvas в виде номерной таблички с флагом и кодом региона;
- Баланс монет уменьшается на **100** за каждую крутку (старт — 1000 🪙);
- Если монет не хватает — выводится сообщение об ошибке.
